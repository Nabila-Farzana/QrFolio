Privacy

QR Profile Generator

This site stores no data

This site is a static web page. It has no server code, no database, and no user accounts. The page makes the QR code in your browser. Your details never go to this site.

Where your details go

All of the details that you type stay inside the QR code and inside the link that the QR code holds. A browser does not send the part of a link after the "#" character to the web server. Anyone who scans the QR code can read those details, so add only the details that you want to share.

Your files

This site does not store, copy, or upload your attachments. The QR code holds only the links to your files. Your files stay in your own Google Drive, your own Dropbox, or another place that you choose.

Google Drive and Dropbox

The buttons for Google Drive and Dropbox are optional. The page loads the Google or Dropbox scripts only after you click one of those buttons.

If you use the Google Drive button, the site asks for the drive.file permission. This permission covers only the files that you select or upload with the button. The site cannot see your other files. The site uses this permission for two actions: it reads the name of each file that you select, and, after you agree, it changes the sharing of that file to "Anyone with the link can view".

The login token stays in the memory of your browser tab. The site does not save it and does not send it anywhere else. Close the tab, and the token is gone. You can remove the permission at any time at your Google Account permissions page.

Cookies and tracking

This site uses no cookies, no browser storage, and no analytics.

Hosting

GitHub Pages hosts this site. GitHub can record standard technical data, for example the address of the page and the internet address of the visitor. The details in the QR link are not part of that record.
